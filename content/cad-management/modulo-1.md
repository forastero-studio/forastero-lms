# Taller de Documentación de Obras

## Contenido

Este módulo cubre el sistema de organización y documentación de obras
usando AutoCAD como herramienta central.

### Temas

- Estructura de archivos y capas
- Sistema de referencias externas (Xrefs)
- Estándares de nominación
- Planillas de documentación
- Entrega de juegos de planos
