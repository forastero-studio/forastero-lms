# Módulo A · Planos de arquitectura

## De qué va este módulo

Este es el módulo fundacional del Taller. Acá no vas a aprender a dibujar planos —eso ya lo sabés—, sino a **organizar el archivo CAD** con un sistema de trabajo profesional, claro y replicable. Es la base sobre la que se monta todo lo que sigue: estructura, instalaciones, terminaciones, carpinterías.

Vas a salir de este módulo con tu propio template de documentación: un listado de layers nombrados según una lógica jerárquica, los CTB para imprimir en escalas 1:50 y 1:100, las referencias para presentar el trabajo en pliegos, y un sistema interno de organización del archivo que vas a usar en cada proyecto a partir de ahora.

La idea no es que adoptes mi sistema como dogma. Es que entiendas la **lógica detrás del sistema** —por qué los layers se nombran así, por qué los colores definen el espesor del trazo, por qué el .dwg necesita una organización interna— y a partir de eso armes el tuyo, o adaptes éste a tu manera de trabajar.

## Qué cubre el video

- Cómo se estructura un archivo CAD profesional desde cero
- Sistema de nomenclatura de layers en jerarquía Grupo · Sub-grupo · Elemento
- Configuración y uso de archivos CTB para impresión consistente
- Referencias externas (XREFs) y su lógica para escalar el trabajo
- Organización interna del .dwg: pestañas, espacios papel/modelo, layouts
- Plantilla base para documentaciones de obra

## Ejercicio del módulo

Tomá el archivo `00.ANTEPROYECTO.dwg` y aplicá el sistema de layers que viste en el video. El objetivo no es terminar el plano —eso se va construyendo módulo a módulo a lo largo del Taller—, sino **dejar el archivo organizado** con la estructura correcta: layers nombrados, CTB asignado, referencias en su lugar.

Cuando termines, vas a tener la base lista para arrancar el Módulo B.

## Qué sigue

En el **Módulo B** vas a aplicar esta misma metodología al plano de estructura: planillas de doblado y armado de hierros, replanteo de muros, trabajo con referencias externas (XREFs).
